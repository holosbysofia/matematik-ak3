Bedömningsunderlag 3 – Matematiskt samtal

Frågor som kan användas för att få syn på elevens tänkande.

1. Hur tänkte du?

2. Kan du visa med en bild eller modell?

3. Varför fungerar din strategi?

4. Finns ett annat sätt?

5. Hur vet du att svaret är rimligt?

6. Vad var svårt?

7. Vilka matematiska ord passar här?

8. Vad skulle hända om vi ändrade ett tal?

Bedömningsunderlag 4 – Från observation till nästa steg

Hjälper läraren att koppla observation till undervisningsbeslut.

1. Vad såg jag? Beskriv konkret vad eleven gjorde, sa eller visade.
2. Vad kan det betyda? Fundera på vilken förståelse eller missuppfattning som kan ligga bakom.
3. Vad behöver eleven möta? Välj nästa representation, fråga, aktivitet eller strategi.
4. Hur följer jag upp? Bestäm när och hur du ska se om stödet gav effekt.
