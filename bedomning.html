🌱 Bedömning som stöd för nästa undervisningssteg

Bedömning i matematik behöver ge information om mer än om ett svar är rätt eller fel. Det viktiga är också att synliggöra hur eleven tänker, vilka begrepp och strategier eleven använder och vilket stöd som behövs för fortsatt lärande.

👀
Observera Vad gör eleven när en uppgift ska lösas?
💬
Lyssna Hur beskriver eleven sitt tänkande?
🧱
Se representationer Kan eleven använda material, bild, tallinje eller symboler?
🧠
Identifiera strategi Är strategin effektiv och begriplig för eleven?
🔎
Analysera Vad verkar eleven förstå och vad är fortfarande osäkert?
➡️
Planera nästa steg Hur behöver undervisningen anpassas?
Viktigt: ett enskilt quiz eller kort test ska inte ensamt användas för långtgående slutsatser. Kombinera elevlösningar, samtal, observationer och återkommande uppgifter.

🧭 Vad kan läraren titta efter?

🔢 Begrepp

  • förstår eleven begreppens betydelse?
  • kan eleven använda begreppen i rätt sammanhang?
  • kan eleven ge exempel och icke-exempel?

🧠 Strategier

  • vilken strategi väljer eleven?
  • är strategin flexibel?
  • kan eleven byta strategi när talen förändras?

🧱 Representationer

  • kan eleven visa med material?
  • kan eleven rita eller använda tallinje?
  • kan eleven koppla modellen till symboler?

💬 Resonemang

  • kan eleven beskriva hur hen tänkte?
  • kan eleven motivera varför en lösning fungerar?
  • kan eleven jämföra två strategier?

🧩 Problemlösning

  • förstår eleven situationen?
  • kan eleven välja relevant information?
  • kontrollerar eleven om svaret är rimligt?

🌱 Självständighet

  • vilket stöd behöver eleven?
  • kan eleven komma igång själv?
  • kan eleven använda tidigare kunskap?
